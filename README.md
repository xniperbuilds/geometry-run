# 🔺 Geometry Run

**Jump rhythmically. Beat the music. Run forever.**

A fast, mobile-first endless rhythm-runner. Tap to jump in time with the beat, dodge the spikes and obstacles, and see how far you can go before one mistake ends the run.

## ▶️ Play

**[xniperbuilds.github.io/geometry-run](https://xniperbuilds.github.io/geometry-run/)**

Best on a phone — tap to jump.

## 🎮 How to play

- **Tap** to jump over spikes and obstacles.
- Time your jumps to the rhythm — momentum never stops.
- One hit ends the run. Beat your distance and climb the leaderboard.

## ✨ Features

- Tight one-tap endless-runner gameplay with rising difficulty
- Real-time global **leaderboard** (Today / This Week / All Time)
- Achievements + stats tracking
- Synthesized sound and music (Web Audio)
- Shareable score card
- Works offline after first load (leaderboard needs a connection)

## 🛠️ Tech

Single self-contained `index.html` — HTML5 Canvas, Web Audio API, and a realtime backend for the leaderboard. No build step, no install.
